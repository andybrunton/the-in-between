Volume pushed along the angle bisector at a joint — ellipse center shifts as the limb bends, with optional squash.

Inputs
Three joint positions (parent, pivot, child), push ratio, orient blend, squash amount, base radius
Output
Ellipse center, orientation, and radii — attach to any volume proxy or deform target

At the pivot joint, average the two bone directions to get a bisector. Push the volume center outward by an amount proportional to how far the joint is from straight. Blend orientation between bisector-normal and chord direction; squash width as bend increases.

Pseudocode 
v1 = normalize(J0 - J1)
v2 = normalize(J2 - J1)
bisect = normalize(v1 + v2)
delta = 180 - jointAngle
offset = avgBoneLength * k_push * sin(delta / 2)
center = J1 + bisect * offset
orient = lerp(angle(bisect)+90Â°, angle(chord), blend)
rx = r0 * (1 - squashFactor * delta/180)
ry = r0

Full formula breakdown 
2D Angle Push — pure 2D bisector push

Given:
  J0 = shoulder, J1 = elbow, J2 = wrist
  L1 = |J1-J0|, L2 = |J2-J1|, Lavg = (L1+L2)/2
  theta = joint angle (180 = straight)
  delta = 180 - theta

1. Vectors from elbow:
  v1 = normalize(J0 - J1)
  v2 = normalize(J2 - J1)
  v_bisect = normalize(v1 + v2)

2. Push:
  offset = Lavg * k_push * sin(delta/2)
  C = J1 + v_bisect * offset

3. Orientation:
  ang_bis = atan2(v_bisect.y, v_bisect.x) + Ï€/2
  ang_chord = atan2(J2.y - J0.y, J2.x - J0.x)
  ang_final = lerp(ang_bis, ang_chord, blend)

4. Squash:
  squash = 1 - 0.85 * (delta/180) * k_scaleX
  rx = r0 * squash
  ry = r0
