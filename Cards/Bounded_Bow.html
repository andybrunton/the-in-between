A symmetric bow curve between two endpoints — bulge grows as span compresses, shaped by eased Bezier tangents.

Inputs
Start & end positions, rest / min span, bulge weight, tangent weight, bend angle, easing mode
Output
Curve path (Bezier CVs or sampled points) — same math in any DCC or engine

Compression drives bulge height through an easing curve so the bow doesn't pop. Tangent weight sets handle span; bend angle projects height via cosine for out-of-plane twist. The visible apex comes from de Casteljau midpoints of a cubic Bezier.

Pseudocode 
L = distance(start, end)
t = (L_rest - L) / (L_rest - L_min)
h = weight * ease(t, mode) * maxHeight * cos(bendAngle)
half = L / 2
tan = half * tangentWeight
P0, P3 = start, end
P1 = start + tangent_dir * tan + normal * h
P2 = end   - tangent_dir * tan + normal * h
curve = cubic_bezier(P0, P1, P2, P3)  // or de_casteljau_apex(P0..P3)

Full formula breakdown 
1. Compression & Bulge (Y-Axis):
   t_norm = (L_rest - L) / (L_rest - L_min)
   t_eased = evaluate_easing(t_norm, mode)
   h_eff = weight * t_eased * max_height * cos(bendAngle)

2. Spans & Tangents (X-Axis):
   halfSpan = L / 2
   tangentSpan = halfSpan * tangentWeight

3. Base Bezier Points (P0-P3):
   P0 (Start Node) = (0, 0)
   P1 (Tangent A)  = (tangentSpan, h_eff)
   P2 (Tangent B)  = (L - tangentSpan, h_eff)
   P3 (End Node)   = (L, 0)

4. SVG Curve Interpolation (Midpoints):
   M01 = average(P0, P1)
   M12 = average(P1, P2)
   M23 = average(P2, P3)
   M012 = average(M01, M12)
   M123 = average(M12, M23)
   Apex = average(M012, M123)
